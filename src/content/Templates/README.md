# Templates

This folder contains templates for creating new blog posts.

## Available Templates

### Blog Post Template.md
- Basic template for use with the **core Templates plugin**
- Manual insertion via `Ctrl+Shift+T`
- Static date format

### Blog Post Template (Templater).md
- Enhanced template for use with **Templater plugin**
- **Auto-inserts** when creating files in `blog/` folder
- **Auto-fills current date** using Templater syntax: `<% tp.date.now("MMM DD YYYY") %>`

## Usage

### With Templater (Recommended)
1. Install Templater plugin
2. Create new file in `blog/` folder
3. Template auto-inserts with current date!

### With Core Templates Plugin
1. Create new file
2. Press `Ctrl+Shift+T`
3. Select "Blog Post Template.md"
4. Manually update the date

## Customizing Templates

You can edit these templates to add:
- Default tags
- Common sections
- Your writing style preferences
- Additional frontmatter fields
